## The Halting Problem

Is it possible to define a function `halts?`? 

The `halts?` function would be defined as follows:

> For the given function and object, return true if the function returns a value and false if it fails or runs forever.

Well, I bet you we could figure out a solution for this kind of function:

`(define (id x) x)`

And probably this one, too:

`(define (inc x) (+ x 1))`

But the question here is, can we define a *general decision procedure* for any given function `f`?

The answer is no. I'll show you how.

Let's take the following code as an example:

```scheme
(define (run-forever) (run-forever))

(define (try p)
    (if (halts? p p)
        (run-forever)
        'halted))

(try try)
```

No matter what `halts?` returns, it's wrong.

If `halts?` returns true - that is to say, the `try` function *does* return a value - it's wrong.
In `try`, if `halts?` returns `true`, `try` evaluates `run-forever`! So it clearly halts!

If `halts?` returns false - that is to say, the `try` function runs forever - that's also wrong.
In `try`, if `halts?` returns `false`, `try` *returns* `'halted`! So it clearly doesn't run forever!

Thus, it is impossible to define a function `halts?` with the aforementioned properties.
