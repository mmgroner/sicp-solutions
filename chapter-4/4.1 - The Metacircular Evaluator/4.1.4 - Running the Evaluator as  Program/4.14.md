# 4.14

> Eva Lu Ator and Louis Reasoner are each experimenting with the metacircular evaluator. Eva types in the definition of map, and runs some test programs that use it. They work fine. Louis, in contrast, has installed the system version of map as a primitive for the metacircular evaluator. When he tries it, things go terribly wrong. Explain why Louis’s map fails even though Eva’s works.

**TL;DR - The representation of procedures is different.**

## Explanation

In our metacircular evaluator, a procedure is a list that looks like this:

```scheme
('procedure (a b c) (* a b c) <env>)
```

In the underlying Scheme, procedures are represented differently.

The underlying Scheme version of `map`, uses the underlying version of Scheme, which calls it's own version of `apply` which does not recognize this representation of procedures.
