## a. What is Wrong with the Plan?

If Louis moves the predicate clause for `application?` to be before the ones for assignment, assignment will not be possible.
In fact, any program using assignment will crash.
The evaluator will recursively evaulate the token `define` which will cause an error, because it's not a pair, and it's not a variable.

The reason is because the predicate `application?` simply checks if the expression is a pair. If so, it will return true. That means that any list (and everything in Lisp is a list except for variables, primitives, quotations, and self-evaluating values) will be evaluated as a procedure call.

## b. How can we Edit `eval` to Accomodate Louis' Plan?

```scheme
(define (application? exp) (tagged-list? exp 'call))
```

By requiring every application to explicitly use the keyword `call`, we can ensure that the evaluator will not evaluate any false positives for application calling.
