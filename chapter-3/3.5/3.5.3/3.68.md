# 3.68

Louis' version of `pairs` will recurse infinitely, because the second argument of `interleave` is not `delayed`.

For example:

```scheme
(interleave
	(1 . #<promise>)
	(interleave
		(2 . #<promise>)
		(interleave
			(3 . #<promise>)
			(interleave
				...
					and so on
						infinitely))))
```
