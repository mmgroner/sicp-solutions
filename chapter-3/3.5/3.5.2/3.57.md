# 3.57

If we were not to memoize `fib`, we would need to make `n` additions twice. When the stream branches out to `(stream-cdr fibs)` and `(fibs)`, all computations must be made for each branch. When memoized, the addition is performed once for both streams.

My initial sketch of this was that the Big Theta of `fibs` is `2n-1` - `2n` for 2 streams, `-1` because one branch doesn't reach until `n`. However, upon closer examination, it would seem that the more precise answer is:

If `A(n)` is the amount of additions for a single stream (because remember, 0 and 1 do not require additions), then the Big O of `fibs` is `A(n) + A(n-1)`. See "xdavidliu"'s answer (2nd from top) on [the wiki page](http://community.schemewiki.org/?sicp-ex-3.57).
